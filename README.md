# 하위문서 자동 생성기

관리계획서(CP, .xlsx)를 업로드하면 하위문서를 자동으로 생성하는 Streamlit 앱입니다.

## 로컬 실행

```bash
python -m streamlit run app.py
```

브라우저에서 `http://localhost:8501` 로 자동으로 열립니다.

## 구성 파일

- `app.py` — Streamlit 화면(UI). CP 파일 하나를 업로드하면 탭별로 4개 문서를 모두 생성.
- `cp_loader.py` — CP 파일(.xls/.xlsx) 공통 로더.
- `generate_is.py` — 검사표준서 변환 로직.
- `generate_screw.py` — 스크류 점검일지(마모도 검사 기준) 변환 로직 (CP 공정특성 '스크류 직경'의
  규격을 스크류 판정 OK 치수에, OK 하한 바로 아래값 + ' 이하'를 판정 NG 치수에 채움, 시트명은 설비번호).
- `generate_equipment.py` — 설비일상점검표 변환 로직 (CP 관리기록방법이 '설비 일상 점검표'인 행을
  위에서부터 No./공정단계명/공정특성/규격으로 채우고, 표 전체에 실선 테두리, 시트명은 설비번호).
- `generate_molding.py` — 셋업 & 일일 성형조건 기록지 변환 로직 (CP 관리기록방법이 '셋업 & 일일
  성형 조건 기록지'인 행을 위에서부터 No./공정단계/공정특성/규격치·공차·단위로 채움. S1·R/S2 는
  CP 주기표시(AC/AD)에서 옮김. 표 헤더/데이터 시작 행/열 위치는 템플릿에서 자동 탐지).
- `IS_template.xlsx` / `screw_template.xlsx` / `equipment_template.xlsx` / `molding_template.xlsx` — 각 문서 서식 템플릿.
- `requirements.txt` — 의존 패키지 목록.

## CP 파일 형식 안내

- `.xls`(구형) 파일은 엑셀에서 `.xlsx`로 변환 후 업로드해야 합니다.
- CP 시트의 `관리표준` 컬럼 값이 `검사표준서`인 행만 추출해서 사용합니다.

## 나중에 웹으로 배포하려면

코드를 바꿀 필요 없이 그대로 서버에 올리면 됩니다. 예시:

- **가장 간단**: Streamlit Community Cloud (무료, GitHub 저장소 연결만 하면 배포됨)
- **사내 서버**: 사내 서버에 Python + 이 폴더를 올리고
  `streamlit run app.py --server.address 0.0.0.0 --server.port 8501` 로 실행,
  방화벽에서 해당 포트를 열어주면 사내망에서 브라우저로 접속 가능.
- **Docker**: `python:3.12-slim` 베이스 이미지에 `requirements.txt` 설치 후
  동일하게 `streamlit run` 실행하는 Dockerfile을 만들면 어디든 컨테이너로 배포 가능.

로그인/권한 분리가 필요해지면 Streamlit 자체 인증 기능이나 리버스 프록시(예: nginx + SSO)를
앞단에 붙이면 됩니다.

## 알려진 한계 / 확인이 필요한 부분

- **제품명**: CP에 별도 필드가 없어 검사표준서는 프로젝트명으로 대체 채움.
- **설비일상점검표 / 성형조건기록지**: CP의 관리기록방법 값으로 행을 골라 CP의 공정단계·공정특성·
  규격을 그대로 옮깁니다(코드에 라벨을 넣어두지 않음 — CP가 바뀌면 그대로 반영). 날짜별 칸은
  작업자 수기 입력용이라 빈 칸입니다.
- **검토표시본 CP**: 공정특성/규격 뒤의 주석(🔍/⚠️/❌, [REVIEW]/[MISSING])은 잘라내고, 해당 항목은
  결과의 `CP에서_못찾은_항목` 으로 안내합니다.
- **성형조건기록지의 공정단계**: CP 공정명(B열)을 이어받아 채웁니다. CP에 공정명이 비어 있으면
  직전 값이 그대로 내려옵니다.
